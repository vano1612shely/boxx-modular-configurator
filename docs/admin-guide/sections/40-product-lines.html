Chapter 3Product Lines

A product line is a range you sell — BOXXPlex, EDUPlex, Mobile Office. It is the first thing a customer chooses, and it carries the rules that decide which size of building they end up with.

Where /admin/collections/building-lines · Catalog → Product Lines

What a product line is

A line is the family; a Building Model is one size within it. The BOXXPlex line might have models for 2, 4, 6 and 8 offices. The customer never picks a model directly — they pick the line and say how much space they need, and the configurator hands them the smallest model in that line which holds the request.

So a line holds the things that are true of the whole range: its name, the word it counts in, the regulations it must satisfy, and the markets it is sold in.

A line on its own does nothing

A line with no building models attached cannot be offered to anyone — there is no size for the configurator to hand over. Create the line first, then add models to it (Chapter 4).

Fields

Regions The markets this range is sold in. Leave empty to sell it everywhere. See Chapter 2.

Creating a product line

  1. Go to Catalog → Product Lines and select Create New.
  2. Enter the Name, for example BOXXPlex.
  3. Enter the Slug, for example boxxplex.
  4. Choose the Unit label — Offices or Classrooms.
  5. Fill in Rules if restrooms are mandatory above a certain size. Leave both boxes empty if they never are.
  6. Add Regions if the range is restricted. Leave empty to sell everywhere.
  7. Select Save.
  8. Add at least one building model to the line before the range can be offered.

Sizing and restroom rules

This is the only part of a product line with real logic behind it, and it is worth understanding before you fill it in.

The largest size is not set here

There is no "maximum" field. The biggest building this line can offer is simply the largest building model attached to it. Publish a bigger model and the range grows by itself; remove one and it shrinks. This is deliberate — a cap typed by hand drifts out of step with the catalogue it is meant to describe.

The two thresholds

Rules
FieldMeaning
Restrooms required at The unit count at which one restroom set becomes mandatory. A building of this size or larger will always include restrooms, whether or not the customer asked for them. Leave empty if restrooms are never mandatory.
Second restroom set at The unit count at which a second set becomes mandatory. Leave empty if a second set is never required.

With Restrooms required at set to 4 and Second restroom set at set to 10, the line behaves like this:

Example thresholds
Customer asks forRestroom sets required
1–3 officesNone. The customer may still choose to add some.
4–9 officesOne set, always.
10 or moreTwo sets, always.
The rules set a floor, not a ceiling

A customer can always ask for more restrooms than the rules demand, and will get them if a model provides that many. They can never end up with fewer.

How a size is chosen

When the customer submits their answers, the configurator picks a model in three passes:

  1. Discard every model in the line smaller than the requested unit count. If nothing is left, the customer is over capacity and sees the message set in Configurator settings.
  2. Of the models that remain, take the smallest — a request for 5 offices is served by the 6-office model, not the 8.
  3. Among models of that same size, take the one with the fewest restrooms that still meets the requirement. If none of them has enough, the one with the most is used rather than refusing the customer.

Editing a product line

Open the line from the list, change what you need, and save. Renaming is safe and takes effect on the next page load — building models point at the record, not at its name.

Changing the slug breaks existing links

The slug appears in every address that opens this range directly, such as /configurator?building=boxxplex. Change it and those links stop resolving — a visitor following an old one is told nothing was found. Treat the slug as permanent once the line is public, and change it only alongside the links that use it.

Changing the unit label changes the question

Switching a line from Offices to Classrooms changes the wording customers are asked, and the wording used to describe the building afterwards. It does not change any building model attached to the line. Only switch it if the range genuinely counts in the other thing.

Deleting a product line

Open the line, use the ⋯ menu beside Save, and choose Delete.

Check the building models first

Every building model belongs to a line. Deleting the line leaves those models without one, and a model with no line cannot be shown to anyone — the range simply disappears from the configurator. If you are retiring a range, the safer route is to remove its models first, or to restrict the line to a region you do not publish, and delete it once you are sure nothing depends on it.

What the customer sees

In the configurator

Product lines are the first question a customer is asked, and the answer decides everything that follows.

Step 1 — which building

Every product line available in the customer's region appears as an option, listed alphabetically by name, showing the Name exactly as you typed it. Choosing one moves straight to step 2.

Step 2 — how much of it

The name of the line the customer just picked appears above the question. The counter beneath it is labelled according to the line's Unit label: lines counted in offices get the Offices label from Configurator settings, lines counted in classrooms get the Classrooms one.

If the customer winds the counter past the largest model in the range, a hint appears under it immediately, before they submit — this is the Over-capacity hint in Configurator settings.

After submitting

The customer lands in the 3D view on the model chosen by the rules above. The address they arrive at carries their answers, so it can be shared or bookmarked:

Address /configurator?building=boxxplex&offices=5&restrooms=1&region=us

The line's name and unit label are used again in the building's summary panel — a 6-office BOXXPlex is described as "6 offices" because of the unit label set here. From this screen the customer can select Change selection to return to step 1 with their answers still filled in.
