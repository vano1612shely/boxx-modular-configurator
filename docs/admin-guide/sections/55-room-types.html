Chapter 5Room Types

A room type says what a room is for — an office, a kitchen, a conference room. It is a short list, and it does two jobs at once: it labels the rooms in your buildings, and it decides which furniture is offered in them.

Where /admin/collections/room-types · Catalog → Room Types

Why one list serves two purposes

When you draw a room in a building you give it a type. When you add a furniture package you say which types it suits. A sofa reaches a lounge only because both records point at the same entry in this list — that is the whole mechanism.

This is why room types are a collection you can edit rather than a fixed list: a new kind of room can be added whenever you need one, and furniture can be aimed at it the same day.

Fields

Room Type
FieldWhat to put in it
NameRequired The type as a person would say it — Office, Kitchen, Conference. Customers read this, so write it for them. Renaming is safe at any time.
SlugRequired The stable key, for example kitchen. Must be unique. Rooms and furniture packages are matched on this and never on the name, so once a type is in use the slug should be left alone.

Creating a room type

  1. Go to Catalog → Room Types and select Create New.
  2. Enter the Name, for example Lounge.
  3. Enter the Slug, for example lounge. Lower case, no spaces.
  4. Select Save.

The new type is available immediately — in the Scene Editor when typing a room, and in the Compatible room types field of every furniture package.

Editing a room type

Renaming is safe and takes effect everywhere at once, because everything points at the record rather than at its text.

Changing the slug silently unmatches things

The slug is how a room and a furniture package recognise each other. Change it on a type already in use and nothing errors — the furniture simply stops being offered in those rooms, and the rooms lose their label. If you must change a slug, afterwards go through every building that uses the type and every package that lists it, and set them again.

Deleting a room type

Open the type, use the ⋯ menu beside Save, and choose Delete.

Rooms already typed with it keep the key they were given, so they are not broken — but with nothing left to translate it, the customer is shown the raw key (lounge) instead of the name (Lounge). Before deleting a type, check which buildings use it and retype those rooms first.

What the customer sees

In the configurator

Two places, both important: the name of the type appears in the room's details, and the type decides what furniture that room is offered.

When a customer opens a room, the details panel names what it is — Type · Office. In a room divided into zones, each zone is listed with its own type instead, because the halves of a divided room are rarely for the same thing.

At the same time, the furniture panel for that room is filtered by the type: only packages listing it under Compatible room types appear at all, and those listing it under Recommended for appear first. Chapter 8 covers both.
