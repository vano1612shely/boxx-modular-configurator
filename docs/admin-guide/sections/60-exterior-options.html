Chapter 6Exterior Options

An exterior option is one thing that can stand at an entrance — a deck, a set of stairs, a ramp, or a combination of them. Customers choose between these when they work round the outside of a building.

Where /admin/collections/exterior-options · Catalog → Exterior Options

What belongs here, and what does not

This collection is a catalogue: what the thing is called, what it looks like, what it costs. It says nothing about where it stands.

Position cannot live here, because the same ramp meets the ground differently on every building. Where an option sits is set per building, in the Scene Editor, against the entrance it belongs to. So the work splits in two:

  • Here — create the option once. Title, model, price, picture.
  • In a building — mark an entrance, offer some of these options at it, and drag each into place. Covered with Building Models.
One option, one model

Each option carries exactly one 3D model. A deck, and a deck with a ramp, are two separate options — which is also how a customer reads them: two cards, two prices. Do not try to express a variation inside one record.

Fields

Exterior Option
FieldWhat to put in it
TitleRequired What the customer reads on the card — Deck with stairs, Deck, stairs and ramp. Be specific: the title is how someone tells two similar options apart.
ModelRequired The 3D model placed at the entrance when this option is chosen. Pick one from 3D Models; upload it there first if it is not in the list (Chapter 9).
Price In US dollars. Left blank, the option is offered with no price shown — which is the right choice for something included as standard.
Thumbnail A picture for the card, from Images. Left empty, the card shows an automatically rendered view of the model instead — usable, but a photograph sells better.
Description A sentence or two under the title on the card. This one is shown to customers.

Creating an exterior option

  1. Make sure the 3D model exists under Media → 3D Models. If not, upload it first.
  2. Go to Catalog → Exterior Options and select Create New.
  3. Enter the Title.
  4. Choose the Model.
  5. Enter a Price, or leave it blank for an option with no price.
  6. Choose a Thumbnail, and write a Description.
  7. Select Save.
  8. Open the buildings that should offer it, and add it to an entrance in the Scene Editor. Until you do this, nobody can see it — creating the option does not put it in front of anyone.

Editing and deleting

Editing is ordinary: open, change, save. Price and description changes reach customers on their next page load.

Changing the model moves what is already placed

Buildings position an option by dragging its model into place at an entrance. Swap the model for a different one and that positioning stays, so a replacement of a different size or shape can end up floating or sunk into the ground. After changing a model, check each building that offers the option.

Deleting leaves an empty choice behind

Buildings point at this record from their entrances. Delete it and those entrances are left with a choice that resolves to nothing. Before deleting, open the buildings that offer the option and remove it from their entrances first.

What the customer sees

In the configurator

Standing outside the building, the customer sees a marker at each entrance that has options. Selecting it opens a panel of cards — one per option offered there — and choosing a card puts that model on the building immediately.

Each card shows the title, the thumbnail, the price if there is one, and the description. The choice is remembered for the session and appears in the request the customer sends you, under its own heading with its price, so the entrances they picked reach you along with the furniture.

The same option in several buildings

One record can be offered by any number of buildings, each positioning it to suit itself. Price and description are edited once, here, and change everywhere at once — which is the reason to reuse an option rather than duplicate it.
