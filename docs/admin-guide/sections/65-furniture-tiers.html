Chapter 7Furniture Tiers

A tier is the grade a furniture package is offered at — Core, Plus, whatever your range calls them. It is a label and nothing more, but it is the label customers use to compare two packages at a glance.

Where /admin/collections/furniture-tiers · Catalog → Furniture Tiers

What a tier does

Exactly one thing: it prints a small badge on the package card. Nothing in the configurator behaves differently because of a tier — it does not affect price, availability, or where a package may go. That makes tiers the safest records in the admin to add, rename or reorganise.

A furniture package does not have to have one. Left empty, its card simply carries no badge.

Fields

Furniture Tier
FieldWhat to put in it
NameRequired The grade as customers read it — Core, Plus, Premium. This is the badge text, so keep it to one short word.
SlugRequired The stable key, for example core. Must be unique. Nothing is matched on it today, but it is what keeps a renamed tier the same tier.

Creating, editing and deleting

  1. Go to Catalog → Furniture Tiers and select Create New.
  2. Enter the Name and a lower-case Slug.
  3. Select Save.
  4. Open the furniture packages that belong to the grade and set their Tier field.

Renaming a tier changes the badge on every package carrying it, at once — this is the ordinary way to rename a grade across the range.

Deleting one leaves the packages that carried it without a badge. Nothing else breaks and nothing disappears from the configurator; the cards simply lose that line. Still worth checking which packages are affected, so the range does not end up half-graded by accident.

What the customer sees

In the configurator

A small badge in the corner of the furniture card, inside a room. That is all.

The badge names the grade only — it deliberately does not repeat the kind of room, because the panel the card sits in already says which room it is offering for.
