Chapter 8Furniture Packages

A furniture package is a set of furniture that customers place as one piece — a desk with its chair and pedestal, a conference table with seating around it. This is the largest collection in the catalogue and the one you will edit most.

Where /admin/collections/furniture-packages · Catalog → Furniture Packages

A package is placed whole

Customers never position individual chairs. They pick a package, it drops into the free space in the room, and they nudge or turn the whole group. That is why a package is one 3D model containing everything in it, and why the space it occupies matters — covered under Footprint below.

Fields

Furniture Package — what it is
FieldWhat to put in it
TitleRequired The name on the card — Office Core, Conference Plus.
Tier The grade badge on the card. Optional; see Chapter 7.
ModelRequired The 3D model, from Media → 3D Models. It must contain the whole group, arranged as it should appear.
Preview Not a field to fill in — a live 3D view of the chosen model, so you can check you picked the right one without leaving the page.
Thumbnail The card picture, from Images. Left empty, the configurator renders a view of the model itself. That works, but a photograph on a plain background sells better and loads faster.
Price In US dollars. Shown on the card and totalled in the customer's request.
Description A sentence about what is in the package.

Footprint — the space it takes up

The footprint is the floor rectangle the package occupies, in metres. The configurator uses it to decide whether the package fits in a room and to keep two packages from standing in the same place.

Measured for you

Width and depth are measured from the 3D model every time you save, so in normal use you leave both boxes empty and never think about them.

Fill them in only when the measured rectangle is wrong for your purposes:

  • Smaller — when the model has an overhang that does not really block the floor, and the automatic measurement makes the package refuse to fit rooms it would sit in fine.
  • Larger — when the piece needs clearance around it to be usable, such as room to pull a chair out.

Where the package is offered

Four fields decide who is shown this package. The first three are filters that must all pass; the fourth only changes the order.

Furniture Package — where it appears
FieldEffect
Compatible lines Which product lines this package is sold with. Empty means every line.
Regions Which markets it is sold in. Empty means everywhere. Works exactly as described in Chapter 2.
Compatible room types Which kinds of room may hold it. Empty means every room. This is the one that decides whether the package appears in the panel at all when a customer opens a room.
Recommended for Room types where it should be offered first. In those rooms it is listed under a "Recommended" heading above everything else. It does not change where the package can go — only the order it is presented in.
Empty means everywhere, not nowhere

All three filters treat an empty list as "no restriction". A brand-new package with nothing filled in is offered in every room of every line in every region. That is convenient for a universal item like a waste bin, and a trap for anything specific — a kitchen unit with no room types set will be offered in the restrooms.

Recommended without compatible is ignored

Recommending a package for a room type it is not compatible with does nothing: it is not offered in that room at all, so there is no list for it to lead. If you add a type to Recommended for, add it to Compatible room types too — unless that field is empty, which already allows every room.

Creating a furniture package

  1. Upload the 3D model under Media → 3D Models if it is not there yet, and a photograph under Images if you have one.
  2. Go to Catalog → Furniture Packages and select Create New.
  3. Enter the Title and choose a Tier.
  4. Choose the Model, and check the preview that appears below it.
  5. Choose a Thumbnail, and enter the Price and Description.
  6. Leave Footprint empty — it is measured on save.
  7. Set Compatible room types. Do this deliberately, even when the answer is "everywhere" — an empty list has consequences.
  8. Set Recommended for, Compatible lines and Regions if the package is restricted.
  9. Select Save.
  10. Open /configurator, enter a room of the right type, and check the package appears and can be added.

Editing and deleting

Editing is ordinary. Remember that the footprint is re-measured on every save, so if you have deliberately overridden it, your values stay only as long as you leave them in the boxes.

Deleting affects requests already sent

A customer's request records which packages they placed. Delete a package and the old requests can no longer show what it was. Consider narrowing its Regions or Compatible lines to take it out of circulation instead, and delete it only once you no longer need to read the requests that mention it.

What the customer sees

In the configurator

Furniture appears only inside a room. When a customer steps into one, a panel opens listing what may go there — filtered by that room's type, and by the line and region of the building they are looking at.

The list is in two parts: Recommended for this room first, then More furniture. If nothing is recommended for the room type, both headings disappear and the list is simply one block — a heading over everything would say no more than no heading at all.

Selecting a card adds the package to the room — dropped into the middle of the free floor, turned sideways automatically if that is the only way it fits. The customer can then move it, turn it, or remove it.

"Too large for this room"

A package whose footprint cannot fit the free floor is still listed, but greyed out and marked as too large rather than hidden. Customers can see it exists and understand why they cannot have it — which is more useful than a short list with no explanation. If a package you expect to be usable shows this, its footprint is the first thing to check.

Everything placed is totalled in the request the customer sends, package by package with its price, grouped by the room it was put in.
