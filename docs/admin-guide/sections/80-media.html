Chapter 9Media

Three collections hold the files everything else points at: Images for pictures, 3D Models for geometry, and Textures for surfaces. Files are uploaded here once and reused across the catalogue.

Upload first, then point at it

A relationship field elsewhere in the admin can only choose from what is already uploaded. When adding something new, always start in Media.

Images

Where /admin/collections/images · Media → Images

Photographs and thumbnails shown in the configurator interface: furniture cards, exterior option cards, building thumbnails, the brand logo, the browser tab icon, and the picture a shared link unfurls with.

Image
FieldWhat to put in it
FileRequired Any image format. Drop it on the upload area or browse for it.
AltRequired A short description of what the picture shows, read aloud by screen readers and shown if the image fails to load. Describe the subject — Corner desk with task chair — not the file.

Two smaller copies are generated automatically on upload, so pages load the size they need rather than the original every time. You never choose between them; the configurator does.

Uploading an image

  1. Go to Media → Images and select Create New.
  2. Drop the file on the upload area, or select it with the browse button.
  3. Write the Alt text. It is required — the record will not save without it.
  4. Select Save.
Deleting an image leaves a gap

Furniture packages, exterior options and settings point at images. Deleting one does not stop those records from working — they fall back to a rendered view or to nothing — but the picture you chose is gone. Check what uses it first.

3D Models

Where /admin/collections/models · Media → 3D Models

Every piece of geometry in the product: the buildings themselves, furniture packages, exterior options, and the doors and windows fitted into rooms.

Uploading is done from the list, not the form

At the top of the 3D Models list are two buttons. Use these rather than creating a blank record — they optimise the file in your browser before it is sent, which is what turns a 150 MB export into roughly 11 MB on the server.

The two upload buttons
ButtonUse it for
Upload a model A single self-contained file — .glb, .gltf or .fbx. This is the usual case.
Upload a model folder A .gltf that keeps its textures as separate files beside it. Pick the whole folder and it is packed into one model for you.
Export glTF where you can

FBX files are accepted, but their materials translate only approximately — colours and finishes may not survive. If your modelling software can export glTF or GLB, use that.

What you see after uploading

Opening a model shows a Title you can edit, a live 3D preview you can turn with the mouse, and a short summary of what the file contains — its size before and after optimisation, and its triangle, mesh, material and texture counts. The summary is filled in automatically and cannot be edited.

The preview is worth a moment every time: it is the quickest way to catch a model that arrived upside down, at the wrong scale, or missing its textures.

Replacing a model can move what depends on it

Buildings position exterior options by dragging their models into place, and furniture footprints are measured from models. Swapping the file for one of a different size or orientation can leave placements wrong. After replacing a model, re-save the furniture package that uses it (to re-measure its footprint) and check any building that positions it.

Textures

Where /admin/collections/textures · Media → Textures

Tileable surface images — wall finishes, floor coverings, ceilings, door and window materials. These are applied to rooms in the Scene Editor, so a room can be given a finish without touching its 3D model.

A texture must tile: its left edge has to meet its right edge without a visible seam, and the same top to bottom. An ordinary photograph of a floor will repeat visibly across a room and look wrong.

Texture
FieldWhat to put in it
FileRequired Any image format. It is re-encoded and resized for you on upload.
Title Optional label — Oak plank, White painted wall. Left empty, the filename is used instead, which is usually unreadable. Worth filling in.
Meta Dimensions and file sizes, filled in automatically after upload. Read-only.
Every texture is capped at 2048 pixels

Larger uploads are scaled down and re-encoded to a compact web format. Nothing is cropped and the shape is preserved — a tile has to keep its full frame to go on tiling — so you can upload a large source without thinking about it.
